Compound Name → KEGG ID Converter

v0.1.3 · Released

A utility to map chemical compound names to their corresponding KEGG identifiers, streamlining a common but tedious step in metabolomics annotation and pathway analysis. Handles name variants and batch conversion from a list of compounds.

Python KEGG API Metabolomics Bioinformatics
